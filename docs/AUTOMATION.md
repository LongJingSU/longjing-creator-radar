# 每天自动更新的接入方法

工作台保存采集结果与开关，**不内置浏览器爬虫或定时调度器**。`npm start` 只启动界面服务；“自动采集”开关控制下一轮是否允许采集，不创建操作系统或智能体任务。首次安装显示“待接入”。

## 接入步骤

1. 先让当前智能体按 COLLECTION.md 跑通一轮实际采集。
2. 用户要求日更后，在智能体提供的真实定时任务工具中注册“每天北京时间 12:00”。不同产品的入口不同，优先使用当前环境已有工具及其文档；本仓库不绑定特定厂商或历史会话。
3. 调度任务必须能访问这个克隆目录、Node.js、用户授权的浏览器会话。任务提示词需填写本机实际绝对路径，而不是作者的路径。
4. 注册成功后，可用下面的本地脚本记录调度器返回的真实任务 ID。这个脚本**只更新界面登记，不创建任务**。

```bash
node scripts/link-schedule.mjs --id YOUR_ACTUAL_TASK_ID
```

5. 等首次执行后检查“采集记录”的时间、覆盖与结果。任务注册成功不代表未来采集保证成功。

本版页面展示的是北京时间 12:00 这一默认约定。若需要其他时间，先修改外部实际任务，并同步前端展示；不要只改页面文字就宣称时间已生效。

## 给调度器的任务提示词

将 `项目绝对路径` 替换为实际克隆目录。

```text
在「项目绝对路径」为龙井自媒体工作台执行一轮真实采集与更新。
先读取 COLLECTION.md，再运行 node scripts/status.mjs。
尊重 settings.enabled 及每条监控的启停和归档状态。暂停时跳过。
读取最新 collectionPlan 与 demandPolicy，使用受支持的浏览器工具访问用户可用的抖音和小红书。
优先最近24小时到7天的新内容、回访增长，覆盖AI工具、AI自媒体、AI硬件及可核验泛热点。
长尾检索之外，尝试至少一个当天实际发现的新词，保留来源。
记录实际内容、评论原话、作者、点赞、日期、出处及核对摘录，未知值留空。
区分累计高互动、首次发现和连续快照支持的增长。
评论需求必须语义复核、出处核验并满足多人重复或高赞问题门槛；不强行出题。
写入本地 inbox，使用 scripts/ingest.mjs 入库，再回读核验。
记录所有失败和覆盖缺口，不能伪造完成。不要覆盖用户稿件和进度。
不得自动发布或发送消息。正常完成、没有可行动变化或已知问题未变时保持安静。
只有确需用户恢复浏览器登录或连接时，提出一次具体必要操作，不重复催促。
```

## 暂停、取消与失效

- 暂停采集：在工作台“定时任务”关闭开关。外部任务仍可能被唤醒，但必须读取开关后跳过采集。
- 取消任务：在外部调度器删除或暂停实际任务；仅清空本地 ID 不会取消调度器里的任务。
- 清除过期登记：外部任务取消后运行 `node scripts/link-schedule.mjs --clear`，页面恢复“待接入”。
- 网页关闭：命令行直接写 SQLite，工作台网页无需常开。
- 设备关机或智能体不可运行：本地任务不能执行，是否补跑由调度器决定。不要补造不存在的采集记录。
- 网页登录失效、验证码、502 等：停止受影响入口，保留其他成功数据，批次 issues 记录原因。没有结果不等于没有热点。
- 云端调度器通常无法访问你电脑上的 localhost、文件或浏览器；不能直接拿本地路径当作云端执行环境。
