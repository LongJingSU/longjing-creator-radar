# 把仓库链接交给你的 AI 智能体

仓库地址：<https://github.com/LongJingSU/longjing-creator-radar>

龙井把工作台界面、数据保存与证据判断放在本地；AI 智能体负责看页面、理解上下文和执行采集。支持文件与命令行的智能体可以完成安装；要真实采集，还需要受支持的浏览器控制能力和用户可访问的平台会话；要自动更新，还需要智能体自己的定时调度能力。模型和浏览器能力不由本仓库提供。

## 可以直接复制的请求

```text
请帮我安装并使用这个项目：
https://github.com/LongJingSU/longjing-creator-radar

先阅读 README.md 和 AGENTS.md，克隆到合适的本地目录，检查运行环境并启动龙井自媒体工作台。
我希望监控抖音和小红书的 AI 工具、AI 自媒体、AI 硬件，新热点和新爆款优先。
请用你支持的浏览器工具，读取我能正常访问的平台页面，按 COLLECTION.md 完成首轮真实采集。
评论需求必须留存原话和出处，并满足多人重复或高赞问题的证据门槛；证据不足就不出题。
在你的定时任务系统里，设置每天北京时间 12:00 更新一轮，不发例行晨报。
保留来源、采集时间、数据缺口及运行记录。不得自动发布或发送消息。
如果你不具备浏览器或定时任务能力，请明确告诉我缺少什么，先完成能做的部分。
最后打开工作台，并报告实际完成的安装、采集和调度验收结果。
```

这个请求明确授权安装、采集与注册每天一次的任务。只想体验界面时，改为“启动演示模式，不连接平台、不注册任务”。

## 智能体执行顺序

### 1. 建立工作目录

```bash
git clone https://github.com/LongJingSU/longjing-creator-radar.git
cd longjing-creator-radar
node scripts/doctor.mjs
npm test
npm start
```

保持服务终端运行，在浏览器打开 `http://127.0.0.1:4318`。Windows 的双击启动器会在后台运行。无需 npm install，也不需要模型 API key；智能体本身的订阅或计费由使用者自己的环境决定。

### 2. 读取监控与权限

运行 `node scripts/status.mjs`。若 settings.enabled=false，尊重暂停，停止采集。首次可在“赛道监控”修改关键词，或在“账号”添加对标账号。不要把演示实例 4320 当作生产实例。

先确认用户的浏览器连接。登录由用户使用自己的账号完成。遇到登录失效、验证码、访问限制，记录受影响入口，不使用抓凭据、私有接口或规避机制。不要把浏览器权限当成仓库自带功能。

### 3. 做一轮真实采集

严格执行根目录 COLLECTION.md。逐个读取 collectionPlan 中启用入口；近期内容、回访快照、历史参考分开记录。从实际可见页面保存标题、链接、作者、日期、累计点赞与评论；泛热点的热度值不能冒充点赞。

把本轮 JSON 写入 `inbox/`（目录不存在时创建）。正常日更使用 `daily-YYYY-MM-DD`；额外的人工采集使用清晰、唯一的 runKey。导入前检查是否已有相同 runKey。重复 runKey 会直接返回旧运行结果，不会追加数据；需要补充时使用一个新的、说明用途的 runKey。

```bash
node scripts/ingest.mjs inbox/YYYY-MM-DD.json
node scripts/status.mjs
```

填写真实日期后再执行。`examples/batch.template.json` 是空结构模板，不能原样当成采集成功导入。`examples/demo-data.mjs` 是虚构演示，不是待采集素材。

### 4. 回读验收

打开“采集记录”查看本轮状态、实际覆盖与缺口；打开“发现”检查原始来源。使用 `openStore().state()` 或本机只读 `/api/state` 查看已入库的内容、快照、评论和需求。核对原话、署名、点赞及证据摘录，不能只看导入命令返回成功。

首次采集只有累计值；同一内容有可比快照后才讨论增长。未达标的评论只出现在待核验线索中。可能一轮都没有可转选题的需求，这是正确结果。

### 5. 配置日更

继续读 [AUTOMATION.md](AUTOMATION.md)，使用当前智能体真实提供的调度器。注册成功与首次执行成功分开验收。页面关闭也能通过命令行入库；设备关机、智能体未运行或浏览器断线期间，不能保证执行。

## 不同环境能做到哪一步

| 智能体能力 | 可以完成 |
| --- | --- |
| 只能对话、不能运行代码 | 解读说明，指导用户安装；不能声称已经安装 |
| 可以运行本地命令、操作文件 | 启动工作台、导入已取得的真实 JSON、备份和分析 |
| 再有受支持的浏览器控制 | 读取允许访问的页面，完成真实采集与出处核验 |
| 再有持久定时调度 | 按用户指定周期重复采集，执行前检查暂停状态 |

不依赖某一家模型 API；也不是把链接丢给任何聊天机器人就能凭空获得登录和后台执行能力。
